### About

Senior Software Engineer with hands-on experience shipping SaaS products end-to-end — from system design and API architecture to payment integration and deployment. Focused on the .NET ecosystem, with production experience across backend (ASP.NET Core), frontend (Blazor WASM, React, Next.js), and mobile (.NET MAUI).

I build products that generate revenue, not just demos. My recent work includes a contract generation platform with Stripe Checkout integration and a football jersey e-commerce — both handling real users and real payments.

**Core strengths:** distributed systems design, clean architecture, third-party integrations (Stripe, Supabase), and leading projects from zero to production.
